# Python Problem Solving

## Description

This repository contains Python solutions for common problem-solving and algorithm-based questions.

The problems are based on real-world scenarios such as attendance analysis, shopping, rainwater collection, employee performance, banking, networking, and appointment scheduling.

## Topics Covered

* Arrays
* Strings
* Sliding Window
* Hashing
* Set
* Prefix Sum
* Kadane's Algorithm
* Maximum Product Subarray
* Anagram Grouping
* Consecutive Sequence
* Interval Merging
* Two Pointer Technique

## Problems Included

1. Student Attendance Analysis
2. Online Shopping Price Analysis
3. Rainwater Collection System
4. Employee Performance Analysis
5. Product Sales Analysis
6. Customer Purchase History
7. Bank Transaction Analysis
8. Employee Skill Grouping
9. Network Packet Analysis
10. Hospital Appointment Scheduling

## Programming Language

* Python

## Purpose


The purpose of this repository is to practice problem-solving skills and understand commonly used data structures and algorithms in Python.
